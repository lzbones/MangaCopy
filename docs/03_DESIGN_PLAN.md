# MangaCopy 方案设计

> 版本：1.0（2026-09-28）
> 关联文档：[需求](02_REQUIREMENTS.md) · [程序架构](04_ARCHITECTURE.md)

## 1. 核心设计决策

| 决策 | 内容 | 依据 |
|---|---|---|
| 两轮法看图 | S1 先整页版面理解，再裁切分镜逐个细粒度理解 | 视觉模型定位不准，粗 bbox + 裁切放大保细节 |
| 自顶向下零号脚本 | L0 设定冻结 → L1 总述 → L2 分页（携带前页摘要）→ L3 分镜固定字段 → 全面检查+自动修订 | 用户要求逻辑约束自顶向下；L2 串行链保跨页连续性 |
| 混合式生图 prompt | 外貌块确定性拼接（每条全量携带）+ LLM 动态场景 tag | 防漂移（prompt 间人物外观不跳变） |
| 双池解耦生图 | 生成池（pro6000）∥ 校验池（spark）以队列桥接；拒绝回流重生成 | 用户 2026-09-28 指令"两者分别并行做" |
| 树形归并 | L0 分块两两归并（7→4→2→1），每节点检查点 | 单次 7 路大合并多次饿死 GB10 prefill |
| 流式 LLM | 所有请求 stream=True 消费 SSE | GB10 上大调用生成 30-90 分钟；非流式使超时变成总时长上限 |
| 会话槽配对 | 2 连接硬上限；两并发调用必持不同 session → 分落两台 DGX | 用户"两台 DGX 各扛一个并发" |
| 统筹流水线 | DAG：S2 后 [S3→S4→S4b]∥[S5→S6]；S7 只依赖 S5（流水消费 S6 产出）；S4b 只依赖 S3（增量消费校验终态面板） | 用户统筹指令"确定后边生成着视频，边用spark做其他任务" |

## 2. 各阶段算法要点

- **S0**：zip/文件夹 → 规范化拷贝（4 位零填充）→ manifest（页数/分辨率/灰度）
- **S1**：两轮法（版面→裁切→细节），分镜 key `pXXX_YY`，对白中文逐字
- **S2**：L0 分块抽取（2 页/块）+ 树形归并 + 全页覆盖校验修复；L3 并行；逐页+全局检查 → 自动修订 ≤2 轮 → UNRESOLVED 记录
- **S3**：S1 分镜裁块实测像素定桶（vertical 1024×1408 / horizontal 1408×1024 / square 1216×1216）；种子 md5 确定性；负面 prompt 实时加载用户调好的 `api_neg_prompt`
- **S4**：双池（3 生成线程 + 2 校验线程）；standard/hd 双档；preflight 3 次探测加固；校验 pass 且 score≥7 → completed，≤3 次尝试后 needs_review
- **S4b**：S1 对白/拟声词 → LLM 视觉排版（失败回退右上堆叠）→ PIL+PingFang 排印；无字版与有字版并存；**增量**：只排 s4 item 终态面板，轮询直至 s4 终态且无新目标
- **S5**：风格卡（守卫+负面约束）→ 节拍分段（≤15s、单镜≤3 角色）→ 段脚本（逐秒镜头+三线声音+中文对白逐字）
- **S6**：H3 prompt 按 skill 三字段结构；2D→I2VA / 其余→T2VA；身份锁每段重复；六项自检（确定性+LLM 双层）
- **S7**：**流水消费**——从 S5 beats 得期望段集，轮询等 S6 的段 prompt 逐个就绪即生成（不等整阶段）；首帧缺失等 30 分钟后降级 T2VA
- **S8**：单段直拼快路径；多段 xfade+acrossfade 0.45s 音画同步（crf 18）

## 3. 容错与重试体系（分层防御）

| 层 | 机制 | 吸收的故障 |
|---|---|---|
| LLM 调用层 | 超时退避 60/180s×3；json 空流免费去参重试；非 json 空流纳入退避重试；ChunkedEncodingError 中途断流重试 | 慢峰、空流窗口、~15min 服务端断流 |
| 业务层 | `_json_call` schema 校验失败带错误清单重试一次；检查+修订 ≤2 轮 | 模型输出结构错误 |
| Item 层 | 每页/块/分镜/段独立检查点，断点续跑零浪费 | 任何中断 |
| Stage 层 | 严格成功判据（全部成功才算成功）→ 失败触发 DAG 重试 | 部分失败搁浅 |
| 全局层 | 驱动 5 个 DAG cycle，冷却 300s 幂等续跑 | 长时间端点异常 |

## 4. 性能要点（实测数据）

- spark（GB10）：TTFT≈0s，decode ~10 tok/s 为瓶颈；reasoning 占大头；最佳窗口凌晨 04-07 时
- 生图：standard ~5s/张（54 张无间隙流水）；hd ~101s/张
- 视频：~90s/段；全链路 13 页彩排墙钟约 20 小时（含多轮端点故障重试）
