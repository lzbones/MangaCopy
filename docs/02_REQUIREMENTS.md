## 1. 项目定位

构建一套自动化流水线，输入已有的编号漫画（文件夹或 zip），输出三类产物：文字版零号脚本（像素级复刻准备）、复刻分镜图片（无字版+有字版）、复刻分段视频（拼接成片）。个人留存用途。

## 2. 核心需求（用户原始 7 步）

| # | 需求 | 落点阶段 |
|---|---|---|
| 1 | 输入解析：识别 zip/文件夹内数字编号的漫画页 | S0 |
| 2 | 看懂漫画（版面、分镜、人物、对白） | S1 |
| 3 | 零号脚本：先冻结人物/衣服/环境设定 → 总体复述 → 分页脉络 → 分镜细粒度；自顶向下逻辑约束；像素级复刻做准备；**写后必须全面检查** | S2 |
| 4 | 生图 Prompt（Wai 格式）：基于零号脚本细化；**每条 prompt 全量携带人物/衣着描述**（防漂移）；可锚定相似动漫人物；写后全面检查 | S3 |
| 5 | 图片生成：Wai API 按漫画顺序逐分镜复刻；**生图与 LLM 校验并行** | S4/S4b |
| 6 | 视频 Prompt：视频脚本（内容改写/镜头设计/声音设计）；风格可选 2D/3D/真人；遵循 MiniMaxH3 skill 规范；**每段 ≤15s**；人物衣着锚定每段重复；写后全面检查 | S5/S6 |
| 7 | 视频生成：MiniMaxH3 API 按剧情顺序逐段生成，拼接成片 | S7/S8 |

## 3. 交互与工程要求

- 各步骤可确认/可全自动双模式（`--confirm` / `--auto`）
- 既要有图形界面（GUI），也要能在 AI 对话框直接吩咐
- 文件/目录命名规范，设计思路落文档

## 5. 质量红线

- 零号脚本对白必须与源漫画逐字一致（中文汉化本原文）
- 人物外貌/衣着在脚本、prompt、视频 anchor 中必须全量一致（跨阶段对齐）
- 单镜视频 ≤15s、主要角色 ≤3
- 检查不通过的阶段不得放行下游（严格成功判据，无搁浅死角）
