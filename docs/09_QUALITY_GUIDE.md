# MangaCopy 复刻质量评估指南

> 版本：1.0（2026-09-28）
> 用途：人工审查复刻产物（图/视频）时的参考——校验分数含义、已知偏移模式、处置建议。
> 关联文档：[用户手册](08_USER_MANUAL.md) · [测试报告](10_TESTING.md)

## 1. S4 校验分数体系

每张分镜图经 spark 视觉校验，输出：

```json
{"pass": true, "score": 8, "issues": ["具体问题1", "具体问题2"]}
```

| 分数 | 含义 | 系统行为 |
|---|---|---|
| 8-10 | 高度还原 | ✅ completed |
| 7 | 及格（有小瑕疵） | ✅ completed（pass 且 ≥7） |
| 5-6 | 明显偏移 | ❌ 换种子重生成（≤2 次） |
| ≤4 | 严重不符 | ❌ 同上；3 次尝试后标 needs_review |

**needs_review 的含义**：系统保留了 3 次尝试中最好的一张，等人工定夺——不是失败，是"机器尽力了"。

## 2. 已知生图偏移模式（实测归纳）

复刻生图（waiIllustriousSDXL）在以下方面最容易偏移，审查时重点看：

| 偏移类型 | 典型案例 | prompt 层对策（已内置或可调） |
|---|---|---|
| **角色数量漏画** | 脚本 2 只尖耳兽，图只画 1 只 | 角色数已进 prompt；可在 s3_wai.md 加 `(exactly two creatures:1.2)` 类权重 |
| **左右站位颠倒** | 脚本"持杖者居右"，图居中偏右 | 构图 tag（`from side` / `dutch angle`）有时不够精确 |
| **发型/发色漂移** | 齐耳短发画成丸子头 | 人物锚（danbooru 角色 tag）+ 全量外貌 tag 已内置，但无锚角色仍有风险 |
| **衣着细节丢失** | 深色立领制服画成白衬衫 | clothing_states 的 tag 已全量携带；细节丰富的描述可能被模型简化 |
| **构图元素缺失** | 脚本"右上角嵌入小框特写"，图没有 | 复杂版式（嵌入框/倾斜分镜框）是 SD 类模型的弱项 |
| **剪影/背景角色** | 脚本"两名黑装束剪影并立"，图只有 1 个 | 剪影类角色常被模型省略 |

**审查优先级**（对复刻忠实度影响从大到小）：
1. 出场人物是否齐全（数量+身份）
2. 关键动作/姿态是否还原
3. 对白气泡位置是否合理（有字版）
4. 衣着状态是否与人物卡一致
5. 背景环境细节

## 3. 有字版（s4_text）审查要点

| 检查项 | 常见问题 | 处置 |
|---|---|---|
| 气泡位置 | 遮住人物脸或关键动作 | 重跑 s4b 该面板（LLM 排版有随机性） |
| 拟声词位置 | 远离动作发生处 | 同上 |
| 文字内容 | 应与 S1 对白逐字一致 | 核对 `s1_understand/page_XX.json` |
| 气泡重叠 | 两个气泡叠在一起 | 重跑（LLM 排版规则已禁止重叠，偶发） |

## 4. 视频审查要点

| 检查项 | 说明 |
|---|---|
| **首帧一致性**（I2V 段） | 视频首帧应与复刻图一致——MiniMaxH3 的 I2VA 模式锚定 |
| 身份一致性 | 人物在不同段之间不换脸/换装（身份锁 + 服装 tag 每段重复） |
| 对白口型 | 视频人物说中文（汉化本原文），口型大致同步即可 |
| 单段时长 | ≤15s，超出说明分段有误（检查 s5 beats） |
| 音画同步 | 段间 xfade 0.45s 交叉淡化处不应有明显跳变 |

## 5. needs_review 面板的处置流程

```bash
# 1. 查看该面板的 3 次尝试记录
cat data/projects/<id>/s4_validate/pNNN_NN.json

# 2. 看当前保留的图（最好的一次尝试）
open data/projects/<id>/s4_images/pNNN_NN.png

# 3a. 接受现状 → 无需操作（下游照常使用该图）
# 3b. 重试 → 单独重跑该面板（自动换种子）
mcpy cli.py run --project <id> --stage s4 --opts '{"panels":["pNNN_NN"]}'
# 3c. 定向优化 → 修改 s3_prompts/pNNN_NN.json 的 positive 后重跑 s4
```

## 6. 质量统计口径

全量彩排后的质量指标（从 `s4_validate/*.json` 汇总）：

| 指标 | 计算方法 | 健康范围 |
|---|---|---|
| 一次通过率 | attempt=0 即 pass 的面板占比 | ≥50% |
| 平均尝试次数 | 全部 attempts 数 ÷ 面板数 | ≤1.8 |
| needs_review 率 | final=needs_review 的占比 | ≤10% |
| 平均 score | 全部最终得分均值 | ≥7 |
