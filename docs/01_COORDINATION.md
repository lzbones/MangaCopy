# MangaCopy 协作规则（人机工作协议）

> 版本：1.0（2026-09-28）
> 适用对象：任何接手本项目的 AI 助手或人类开发者
> 这些规则由用户许庆副研究员明确指示，具有最高优先级。

## 1. 资源使用纪律（严格执行）

### 1.1 放行规则

**spark（LLM）与 ComfyUI（生图/生视频）的使用，以用户的明确信号为唯一放行依据。**

- 端点慢响应 ≠ 空闲——spark prefill 慢是常态（正常长生成可到 5-10 分钟）
- 端点恢复 ≠ 可用——用户可能在跑自己的任务（如 qoder）
- **判断端点空闲只能靠用户信号，禁止靠探测**
- 用户说"spark 可以测试了" = 放行 spark；说"ComfyUI 空出来了" = 放行 ComfyUI——两者独立放行

### 1.2 严禁脱离式后台脚本

任何消耗 LLM/ComfyUI 的工作**必须在主进程内同步执行**（前台阻塞或 join），严禁 nohup/detach/孤儿进程。原因：暂停令无法触及已脱离的进程——本项目历史上有 4 次此类违规（用户在暂停期间于监控面板看到我们的任务在跑）。

### 1.3 全局并发上限

- spark：**2 个并发连接**（两台 DGX 各扛一个，硬件并行弱，实测 4 并发时 58 分钟零产出）
- ComfyUI：队列自动串行，无需额外控制

## 2. 异常处理流程（严格执行）

```
发现异常 → 报告（现象 + 初步定位 + 可选方案） → 用户确认 → 共同讨论设计 → 实施
```

- **修改任何代码前必须先请示**，经用户确认后才动手
- 批量自主迭代仅在用户明确授权期间生效（如过夜托管"今晚迭代靠你了"），且授权随场景收回、不默认延续
- 报告时把异常现象、根因分析、可选方案（含代价）一并列出

## 4. 环境约定

- **Python**：一律 `~/.ai-env/bin/python`（系统 python3 缺依赖）
- **ffmpeg**：本机无系统级安装，用 `imageio_ffmpeg.get_ffmpeg_exe()`
- **Mac 休眠**：长任务用 `caffeinate -is <command>` 包裹
- **spark 会话亲和**：请求体顶层 `metadata.session_id`（非 header），每次阶段运行用独立 UUID，禁止写死固定字符串
