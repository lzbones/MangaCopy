## 摘要

**MangaCopy** 是一个面向黑白热血/动作漫画全流程自动化复刻与动态视听长片生成的工程系统。系统由两台 NVIDIA DGX Spark（Grace Blackwell GB10 架构，部署 Qwen3.8-27B-NVFP4 推理模型）与一台 NVIDIA RTX PRO 6000 96GB 工作站（ComfyUI 0.37.2+）构成的异构算力集群协同驱动，实现了从原始扫描漫画到零样本文学剧本推导、分镜 SDXL 重绘、中文字体与气泡排版压制、MiniMax-H3 动效视频流式渲染以及多轨音频交叉淡入淡出（xfade）拼接的全链路闭环。

在第 187 话（共 13 页、56 个分镜画格）的方案 B 全量重新生成实测中，系统以标称 480P 规格实现端到端总耗时 **8 小时 51 分 32 秒**（较基准方案大幅缩减 **52.4%**），并完整交付 1 部 101.14 秒动态成片与四大独立出版级静态漫画目录。

## 一、全链路架构与流水线拓扑

系统以有向无环图（DAG）模式驱动，涵盖 S0 至 S8 十个核心计算阶段，在 S2 剧本生成后解耦为静态分支（Branch A）与动态视听分支（Branch B）：

```
                  ┌───────────────┐
                  │ S0 源图校验   │
                  └───────┬───────┘
                          ▼
                  ┌───────────────┐
                  │ S1 分镜理解   │ 页面坐标定位 / 细节提取 / 画格剪裁
                  └───────┬───────┘
                          ▼
                  ┌───────────────┐
                  │ S2 文学剧本   │ L0 设定 / L1 大纲 / L2 分页 / L3 56 镜剧本
                  └───────┬───────┘ (确定性正则修复器，100% 结构闭环)
                          │
         ┌────────────────┴────────────────┐
         ▼                                 ▼
┌─────────────────┐               ┌─────────────────┐
│ S3 生图提示词   │               │ S5 视听分镜设计 │ 11 节拍运镜与风格配置
└────────┬────────┘               └────────┬────────┘
         ▼                                 ▼
┌─────────────────┐               ┌─────────────────┐
│ S4 SDXL 生成质检│               │ S6 H3 动效提示  │ 语法自愈器 100% 通过
└────────┬────────┘               └────────┬────────┘
         ▼                                 ▼
┌─────────────────┐               ┌─────────────────┐
│ S4b 文字排印    │ 矢量气泡压制   │ S7 视频流式渲染 │ PRO 6000 MiniMax-H3 I2V
└────────┬────────┘               └────────┬────────┘
         ▼                                 ▼
┌─────────────────┐               ┌─────────────────┐
│ 静态四目录导出  │               │ S8 终片合成拼接 │ FFmpeg 0.45s xfade 音画同步
└─────────────────┘               └─────────────────┘
  - 纯图画格 (56)                   - final.mp4 (101.14s)
  - 嵌字画格 (56)
  - 纯漫整页 (13)
  - 嵌字整页 (13)
```

## 三、核心工程特性与创新机制

1. **S2 确定性正则修复与标准化器（`_l3_repair`）**：
   - 彻底解决大模型自回归解码中 Markdown 标题层级降级（`###` 代替 `##`）、标题无序排列与缺失导致的质检死锁；
   - 79 个生成项 100% 单次收敛，S2 耗时缩短 45.2%（耗时由 8.2h 压缩至 4h 29m）。
2. **双 Spark 会话池租赁与 100% 负载均衡（`Session Leasing`）**：
   - 引入独立双 UUID 租约池，强制双并发线程分流至两台独立物理端点（`21251` 与 `21252`）；
   - 彻底消除了“单机自回归占用假死、另一台空闲待命”的非对称现象，两台机器利用率均稳定在 100.0%。
3. **S4 双池解耦流水线（Dual-Pool Pipeline）**：
   - RTX PRO 6000 绘图池（单图 5.0 秒）与两台 Spark 视觉质检池（单图 20~45 秒）通过队列异步桥接；
   - 结合 `seed = base + attempt * 7919` 种子扰动重绘，既守住 $\ge 7$ 分质检底线，又实现 GPU 与 LLM 算力 100% 重叠并行。
4. **S7 视频渲染流式流水线**：
   - S7 随 S6 各分段动效提示词落盘即刻触发 PRO 6000 渲染，消减等待气泡，S7 耗时压缩 74.6%（48m 16s）。
5. **四大独立静态漫画目录自动高保真合成**：
   - 基于原版扫描件真实尺寸与 BBox 坐标，将 56 镜无字底图与 49 镜矢量嵌字图精准拼装为 13 页整版纯漫与出版级嵌字漫。

## 五、快速上手与运行指南

### 1. 环境准备
推荐使用虚拟环境 `~/.ai-env`：
```bash
# 激活 Python 环境并验证端点
source ~/.ai-env/bin/activate
python -c "import requests; print('LiteLLM:', requests.get('http://166.111.50.17:4000/health').status_code)"
```

### 2. 命令行执行（CLI）
```bash
# 执行完整全链路（自动调度）
python cli.py run --project data/test_projects/projects/20260930_opt_full13 --stage auto

# 单独执行静态生图分支（S3 -> S4 -> S4b -> 漫画四目录）
python tests/run_branch_a.py
```

### 3. 可视化界面（Gradio GUI）
```bash
python gui.py --port 7860
```
