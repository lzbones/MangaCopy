     输出 JSON：summary（页面概述）/ notes（特殊元素）/ panels[]（no 阅读顺序号、bbox 归一化坐标、shape 形状、reason 要点）。

你是资深漫画编辑。下面是这部黑白日本漫画（中文汉化版）第 <<PAGE_NO>> 页的整页图。

请仔细观察版面，输出该页的版面结构 JSON（字段名用英文）：

{
  "summary": "页面一句话概述（本页剧情要点）",
  "notes": "标题栏/章节号/作者注/汉化组名单/页眉页脚/水印等特殊元素说明，无则空字符串",
  "panels": [
    {
      "no": 分镜阅读顺序号（从 1 开始的整数）,
      "bbox": [x, y, w, h],
      "shape": "vertical|horizontal|square|full",
      "reason": "该分镜内容要点一句话"
    }
  ]
}

要求：
1. 阅读顺序按日式漫画右起规则：从右上角开始，先右列后左列，每列内自上而下；panels 按该顺序编号。
2. bbox 为归一化坐标 [x, y, w, h]：原点在页面左上角，x 向右、y 向下，各分量取值 0~1。
3. bbox 是粗略值即可，但必须完整覆盖该分镜的画面区域，特别是含对白气泡的区域（气泡常溢出分镜边框，务必一并包进 bbox）。
4. shape：竖长分镜 vertical；横宽分镜 horizontal；近方形 square；占满整页或无法从版面中切分的单一大画面 full。
5. 相邻分镜 bbox 允许轻微重叠；不要遗漏任何含画面或对白的区域。
6. 只输出 JSON，不要输出任何其他文字。
