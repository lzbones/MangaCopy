【任务】
把下述 S5 段脚本（<<SEG_KEY>>，目标视频时长 <<DURATION>> 秒）转写为 MiniMax-H3 的最终视频 prompt。模式：<<MODE>>。

【H3 prompt 固定结构（逐字符级别的硬规则）】
1. 模式为 I2VA 时，prompt 第一行必须逐字符为：
<<I2VA_FIRST_LINE>>
第一行之后紧跟一个空行，然后是正文字段。模式为 T2VA 时没有该指令行，直接从正文字段开始。
1.5. I2VA 首帧锚定：[Shot 1] 必须以首帧画面为起点——<<FIRST_FRAME_NOTE>>；先确立首帧中的人物、构图与场景锚点，再向前发展动作（首帧锚定→动作起动→连续发展→结果/反应），人物身份、衣着、颜色、关键物体与空间关系全程保持一致。T2VA 无此要求。
2. 正文按以下顺序且仅含三个字段（字段名逐字符一致）：

integrated_multimodal_description: [Shot 1] ...

overall_soundscape: ...

non_diegetic_music: ...

3. integrated_multimodal_description 规则：
   - 英文正文；[Shot 1] 不带时间戳，开头第一句必须是风格句（使用下方风格卡的 English Style Anchor，含 NOT 守卫）。
   - 后续镜头写作 "[Shot N] At MM:SS.mmm, ..."（如 [Shot 2] At 00:03.500, ...）：Shot 编号从 2 起连续递增；时间戳严格递增；每个时间戳必须大于 0 且小于本段时长 <<DURATION>> 秒。
   - 每个镜头都要重复身份锁：必须严格遵循下方【本段相关角色英文 tag】中的生理性别（绝对严禁男女颠倒混淆）、锚定经典动漫角色与作品出处、发型发色与五官体貌！逐字使用角色名 + 该角色的英文外貌 tags + 英文衣着 tags + 逐字符短语 "identity lock, no identity swap, no changing face or hairstyle"；并锁定镜头内角色数量（如 "exactly two characters appear in this shot"）。单镜主要角色 ≤ 3。严禁脱离锚定角色肆意发挥！
   - 运镜写成自然英文动作句（类型+幅度+速度），如 "The camera pushes in with small amplitude at slow speed toward ..."；景别/机位随 S5 逐秒设计。
   - 对白格式逐字符为：<d>[Chinese] 中文原文</d>——中文原文必须取自下方对白清单，一字不改、不翻译、不增删标点。说话人用稳定 ID (S1)(S2)（按出场顺序编号，跨镜头不变）；说话人首次出现时在其 ID 前给出性别、年龄、音色描述。
   - 画外音/旁白：用逐字符短语 "says in an off-screen voiceover"，且其后必须紧跟说明该角色 "lips remain completely closed"。
   - 画面内可见文字（招牌/字幕等）用英文双引号包裹原文。
4. overall_soundscape：1-4 句英文，仅描述环境声、动作音效与非语言人声（呼吸/脚步/雨声等）；不得重复对白内容；完全静音时才可用 N/A。
5. non_diegetic_music：1-3 句英文，仅描述器乐、节奏、动态变化（角色听不见、观众可听见的配乐）；无配乐时写 N/A。
